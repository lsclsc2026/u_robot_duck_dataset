# 当前进展与后续路线

截至 2026-09-13，本项目交付的是采集、预处理和候选发现工具。

| 阶段 | 状态 | 下一步验收依据 |
|---|---|---|
| 相机录制、session、抽帧、校验、网页浏览 | 已实现；已有历史采集记录，本轮通过合成 bag 测试 | 新设备需确认相机与持久化目录 |
| 固定首轮数据准备 | 历史 160 张图和 4 段/1300 帧片段已准备 | 新数据按 session 重新设计划分 |
| 云端 venv 与 Grounding DINO calibration | 历史完整 100 张/3 提示词扫描完成 | 保存模型哈希、脚本提交与环境清单 |
| calibration 人工审核与配置冻结 | 未完成 | 人工 bbox、TP/FP/漏检、可追溯的审核版本 |
| holdout 60 张评价 | 未完成 | 冻结配置下的独立评价，不用 holdout 调参 |
| SAM2 初始化与连续传播 | 未完成 | 多目标 ID、遮挡恢复、漂移/丢失与质量检查 |
| YOLO 标签导出与最终质检 | 未实现 | 合法归一化 bbox、session 级 train/val 划分、负样本确认 |
| YOLO 模型训练与机器人部署 | 未完成 | 模型版本、独立测试指标、推理演示与部署验证 |

后续目标是从经审核的关键帧初始化 SAM2，传播候选掩码，再导出 `class 0 = duck` 的检测标签。跟踪丢失、重检测、遮挡、重复目标与低质量掩码需要明确策略。是否采用某个 YOLO 版本尚未形成已验证训练链路；本仓库不声称已完成 YOLOv21 训练或部署。

真实负样本应来自明确采集与审核，不得把漏检自动转换成空标签。拟用于 2–5 FPS 导出的帧与保持原始帧率的跟踪输入分别管理，所有输出继续追溯到原始 session 和 SHA256。
